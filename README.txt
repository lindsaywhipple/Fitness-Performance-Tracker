This is a python program command-line workout tracker that allows users to log, view, and manager their fitness data. Users are able to create new workouts, display summaries, and save/load logs via CSV files. 

Features:
- Add new workout
- View all saved workouts (ex. Squats, Deadlifts)
- Save and workouts to and from CSV file
- View summary statistics
- Compare workouts
- Error handling
- Unit tests (test_workout.py)

Requirements: 
- Python 3

Running the program:
- Ensure all files are in the same directory
    - main.py
    - workout.py
    - test_workout.py
    - summary.txt
    - workouts.csv
- Follow on-screen prompts to add or view workouts


To run unit tests:
- Run test_workout.py
